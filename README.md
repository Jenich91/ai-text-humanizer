# AI Text Humanizer

AI Text Humanizer — небольшой Python-инструмент для придания тексту, сгенерированному ИИ, более естественной структуры предложений. Скрипт изменяет разбивку текста, объединяет и разделяет предложения и регулирует вариативность их длины без использования внешних словарей или сторонних библиотек.

## Возможности

- Разделение слишком длинных предложений.
- Объединение коротких соседних предложений.
- Изменение порядка фраз через перестановку по запятой.
- Регулировка burstiness — вариативности длины предложений.
- Настройка интенсивности преобразований.
- Поддержка повторяемых результатов через параметр `entropy`.
- Сравнение статистики исходного и обработанного текста.
- Интерактивный режим ввода в терминале.

## Требования

- Python 3.8 или новее
- Внешние зависимости не требуются

## Запуск

```bash
git clone https://github.com/Jenich91/ai-text-humanizer.git
cd ai-text-humanizer
python humanizer.py
```

После запуска:

1. Введите или вставьте текст.
2. Завершите ввод пустой строкой.
3. При желании задайте энтропию или оставьте поле пустым для случайного результата.
4. Выберите интенсивность от `0.3` до `1.0` или нажмите Enter для значения `0.85`.

## Использование как библиотеки

```python
from humanizer import humanize_statistical, analyze_text

text = "Исходный текст можно обработать прямо из Python-программы."

result = humanize_statistical(
    text,
    entropy="fixed-seed",
    target_burstiness=8.0,
    max_passes=12,
    intensity=0.85,
)

print(result)

analyze_text(text, "ДО")
analyze_text(result, "ПОСЛЕ")
```

### Параметры `humanize_statistical`

| Параметр | Тип | По умолчанию | Описание |
|---|---:|---:|---|
| `text` | `str` | — | Текст для обработки |
| `entropy` | `Optional[str]` | `None` | Соль или seed для детерминированной генерации |
| `target_burstiness` | `float` | `8.0` | Целевая вариативность длины предложений |
| `max_passes` | `int` | `12` | Максимальное количество проходов преобразования |
| `intensity` | `float` | `0.85` | Интенсивность изменений от `0.3` до `1.0` |

## Как это работает

Алгоритм разбивает текст на предложения и оценивает их длину в словах. Затем выполняет несколько проходов:

- разделяет длинные предложения вокруг союзов, запятых или по середине;
- объединяет короткие соседние предложения;
- переставляет фразы в длинных предложениях;
- принудительно разделяет самое длинное предложение при недостаточном burstiness;
- при необходимости изменяет завершающую пунктуацию.

Для каждого запуска с одинаковым значением `entropy` будет использоваться один и тот же генератор случайных чисел.

## Статистика текста

Функция `analyze_text()` выводит:

- количество предложений;
- среднюю длину предложения;
- burstiness — стандартное отклонение длины;
- коэффициент вариации;
- минимальную и максимальную длину в словах.

## Ограничения

- Проект ориентирован на статистическую перестройку текста, а не на семантический анализ.
- Перестановка фраз может менять тон или логику текста, поэтому перед публикацией результат следует проверять.
- Инструмент не гарантирует обход систем определения ИИ-сгенерированного текста.
- Для редактирования смысла и фактов необходима ручная проверка.
